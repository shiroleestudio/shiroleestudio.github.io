답이 없으면 메일 한 통 주세요 · shiroleestudio@gmail.com

정말 무료인가요?

네. 모두 무료이고 가입도 없습니다. 타임라인과 스페이스서퍼 itch.io 웹판에는 광고가 없어요. 스페이스서퍼의 자체 웹판·웹 게임 포털판·모바일 앱판에는 광고가 붙을 수 있고, 판별 내용은 개인정보처리방침에 적어 둡니다.

제 정보를 모으나요?

이름·메일 같은 개인정보는 모으지 않습니다. 설정과 기록은 사용자의 기기 안에만 저장되고, 운영자는 서버를 두지 않아요. 앱별 자세한 내용은 개인정보처리방침에 있습니다.

폰에 앱처럼 설치할 수 있나요?

타임라인은 됩니다. 아이폰은 사파리 공유 버튼 → ‘홈 화면에 추가’, 안드로이드는 크롬 메뉴 → ‘앱 설치’. 한 번 열어 두면 오프라인에서도 열려요.

앱에서 데이터를 지우고 싶어요.

브라우저 설정에서 해당 사이트의 데이터를 지우거나, 홈 화면에 추가한 앱을 삭제하면 기기 안의 기록이 모두 사라집니다.

스페이스서퍼는 언제 나오나요?

만드는 중인 개발자 버전은 모든 단계가 열린 채로 지금 해볼 수 있어요. 정식 무료 웹판은 itch.io에 먼저 엽니다. 날짜가 정해지면 소식에 올려요.

타임라인 내용이 틀렸어요.

고맙습니다. 항목 이름과 바른 내용, 가능하면 근거 자료 링크를 메일로 보내 주세요. 확인되면 고치고 출처를 붙입니다.
